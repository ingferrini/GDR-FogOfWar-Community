# Security / Sicurezza

Non pubblicare vulnerabilità, file di progetto, percorsi locali o dati sensibili in una issue ordinaria. Usa **Report a vulnerability** nella scheda Security del repository. Includi versione, impatto, prerequisiti e passaggi minimi per riprodurre il problema.

Do not disclose vulnerabilities, project files, local paths, or sensitive data in a regular issue. Use **Report a vulnerability** in the repository Security tab. Include the version, impact, prerequisites, and minimum reproduction steps.
