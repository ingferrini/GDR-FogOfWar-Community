# Contribuire / Contributing

## ITA

- Apri una **Bug report** per problemi riproducibili e compila tutti i campi obbligatori.
- Apri una **Richiesta funzionalità** per proporre miglioramenti coerenti con sessioni dal vivo e proiezione al tavolo.
- Cerca prima tra le issue esistenti e collega eventuali duplicati.
- Una issue deve descrivere un solo problema o una sola proposta.
- Non inviare pull request: il sorgente è privato e le modifiche vengono integrate dal maintainer.

## ENG

- Open a **Bug report** for reproducible problems and complete every required field.
- Open a **Feature request** for improvements that fit in-person play and tabletop projection.
- Search existing issues first and link possible duplicates.
- Each issue should describe one problem or one proposal.
- Do not submit pull requests: the source is private and changes are integrated by the maintainer.
